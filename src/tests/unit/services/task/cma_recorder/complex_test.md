| Группа | Имя теста (ID) | Пояснение (Test Doc) |
| --- | --- | --- |
| **Нормализация входов** | `calc_relative_load` | Расчет относительной нагрузки (Load / LoadNom) для крана и лебедок. Проверка работы при нулевых и граничных значениях. |
|  | `calc_op_cycle_threshold` | Динамический расчет порога 5% от номинала для определения начала рабочего цикла. |
| **Определение рабочего цикла** | `detect_crane_is_active` | Фиксация активности крана с учетом гистерезиса нагрузки (FnThreshold) и таймеров задержки (TimerOnDelay, TimerOffDelay 5000ms). |
|  | `detect_winch_is_active` | Фиксация активности индивидуальных лебедок с учетом задержек и индивидуальных номиналов. |
|  | `detect_op_cycle_active` | Агрегация активности (OR) крана и лебедок в единый флаг рабочего цикла. |
|  | `detect_pump_is_active` | Проверка совпадения активности гидростанции с активностью рабочего цикла. |
|  | `detect_op_cycle_edges` | Выделение переднего (Started) и заднего (Done) фронтов рабочего цикла для сброса интеграторов и отправки SQL-батчей. |
| **Формирование ID цикла** | `gen_op_cycle_id` | Инкремент и сохранение (FnRetain + FnAcc) сквозного идентификатора по началу каждого нового рабочего цикла. |
| **Расчет основных метрик** | `calc_crane_cycle_avg_load` | Сбор и фиксация (FnHold + FnAverage) средней нагрузки на кран за цикл. |
|  | `calc_winch_cycle_avg_load` | Сбор и фиксация средней нагрузки на каждую лебедку за цикл. |
|  | `calc_crane_cycle_max_load` | Сбор и фиксация (FnHold + FnMax) пиковой нагрузки на кран за цикл. |
|  | `calc_crane_op_cycle_secs` | Подсчет длительности (FnTimer) активного состояния цикла в секундах. |
|  | `calc_alarm_class` | Расчет класса тревоги. Суммирование Overload > 25% (Class 4), Overload > 10% (Class 2) и срабатываний SWL. |
|  | `calc_crane_eigen_value` | Расчет характеристического числа крана (усталость по кубу максимальной относительной нагрузки). Обновление стейта по завершению цикла. |
|  | `calc_winch_eigen_value` | Расчет характеристического числа лебедок (усталость по кубу средней нагрузки, умноженная на длительность). |
| **Расчет диапазонов загрузки** | `eval_load_ranges_matrix` | Формирование 13 логических флагов попадания средней нагрузки (0.05..1.25+) по итогам цикла (FnAnd + FnGe + FnLt). |
|  | `eval_cycle_load_range_str` | Каскадный выбор (FnSelect) строкового ключа диапазона ('0_05-0_15' и т.д.) на основе матрицы логических флагов. |
| **Накопители (Basic Metrics)** | `metric_total_op_secs` | Накопление общего времени работы в секундах (FnSql UPDATE) для крана, лебедок и насосной станции. |
|  | `metric_total_cycles_count` | Инкремент суммарного числа рабочих циклов (по заднему фронту). |
|  | `metric_cycles_distribution` | Инкремент счетчика циклов в конкретной корзине диапазона нагрузки (используя строковый ключ диапазона). |
|  | `metric_mass_distribution` | Суммирование поднятой массы в конкретной корзине диапазона нагрузки. |
|  | `metric_total_lifted_mass` | Суммирование общей массы всех поднятых грузов для крана и индивидуально для лебедок. |
|  | `metric_swl_trip_count` | Инкремент счетчика срабатываний ограничителя грузоподъемности по переднему фронту датчика (SWLProtection). |
|  | `metric_eigen_value_sync` | Запись текущего характеристического числа (FnSql UPDATE) в БД по завершении цикла. |
| **Журнал рабочих циклов** | `export_op_cycle_record` | Запись в БД `rec_operating_cycle` с таймстемпами начала/конца и Alarm Class. |
|  | `export_op_metric_record` | Запись в БД `rec_operating_metric` значений average_load и max_load с привязкой к ID цикла. |
| **Телеметрия и события (Live)** | `live_mops_event` | Экспорт в БД событий CraneMode.MOPS по факту их изменения (IsChangedValue). |
|  | `live_aops_event` | Экспорт в БД событий CraneMode.AOPS по факту их изменения. |
|  | `live_dynamic_deadband` | Расчет плавающего порога чувствительности (PiecewiseLineApprox) от 30% на пустом крюке до 0.1% на максимальной нагрузке. |
|  | `live_load_filter_event` | Экспорт в БД изменения нагрузки крана и лебедок. Срабатывает только при превышении динамического порога (FnThreshold) для снижения шума. |
