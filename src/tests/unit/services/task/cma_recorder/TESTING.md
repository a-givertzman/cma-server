Полный структурированный перечень функций (фич) регистратора, вытащенный из топологии YAML-конфига.
Разбиты на логические блоки, чтобы тесты можно было писать изолированными группами — от математики до экспорта в базу.

### 1. Детектирование и управление рабочим циклом (Cycle Management)

Блок отвечает за физику процесса: понимание, когда агрегат начал работу и когда закончил.

| Латинский префикс (Test ID) | Фича / Узел графа | Пояснение для тестов |
| --- | --- | --- |
| `cycle_threshold` | Порог начала цикла | Расчет 5% от номинала (`LoadR0`) для крана и лебедок. |
| `cycle_activity` | Активность механизмов | Фильтрация дребезга датчиков. Задержка TON/TOF (5 сек) для `craneIsActive` и лебедок. |
| `cycle_state` | Состояние цикла | Агрегация активностей (OR) и выделение фронтов: `opCycleIsStarted` (Rising) и `opCycleIsDone` (Falling). |
| `cycle_id_gen` | Генерация ID цикла | Инкремент `opCycleId` по переднему фронту и сохранение в `Retain` (диск). |
| `cycle_timer` | Длительность цикла | Секундомер `craneOperatingCycleSecs`, сбрасываемый на старте нового цикла. |

### 2. Математика: Метрики цикла (Cycle Aggregations)

Сбор данных внутри одного конкретного цикла. Сбрасываются при начале нового.

| Латинский префикс (Test ID) | Фича / Узел графа | Пояснение для тестов |
| --- | --- | --- |
| `metric_load_relative` | Относительная нагрузка | Приведение фактической нагрузки к процентам от номинала (`Div`). |
| `metric_avg_load` | Средняя нагрузка | Накопление среднего значения (`Average`) с фиксацией результата (`Hold`) для крана и 3-х лебедок. |
| `metric_max_load` | Максимальная нагрузка | Поиск пикового значения (`Max`) с фиксацией результата (`Hold`) за цикл. |
| `metric_alarm_class` | Класс аварийности | Определение тяжести цикла (0, 1, 2, 4) через `PiecewiseLineApprox` на базе перегруза (>110%, >125%) и срабатываний SWL. |
| `metric_eigen_value` | Характеристическое число | Накопление кубической усталости по ГОСТ (`Pow 3.0`). Для крана база — пик (`Max`), для лебедок — среднее (`Average`). |
| `metric_load_range` | Маршрутизация диапазонов | Определение попадания нагрузки в одну из 13 корзин (0.05-1.25+) через цепочку `Select` без ветки default. |

### 3. Накопительные счетчики (Basic Metrics Totalizers)

Глобальная статистика, живущая годами. Постоянно пишет инкременты в БД (`rec_basic_metric`).

| Латинский префикс (Test ID) | Фича / Узел графа | Пояснение для тестов |
| --- | --- | --- |
| `accum_op_hours` | Моточасы (мото-секунды) | Интегрирование времени работы (`Timer`) для крана, насоса и лебедок. |
| `accum_cycles_count` | Счетчик рабочих циклов | Безусловный инкремент (+1) по заднему фронту `opCycleIsDone`. |
| `accum_lifted_mass` | Поднятая масса | Суммирование средней массы за каждый завершенный цикл (в тоннах). |
| `accum_swl_trips` | Срабатывания SWL | Подсчет фактов перегруза лебедок (выделение переднего фронта концевика + Аккумулятор). |
| `accum_distribution` | Распределение нагрузок | Обновление счетчиков (Count) и суммарных масс (Load) по 13-ти корзинам на основе `cycleLoadRange`. |

### 4. Экспорт метрик цикла (Cycle DB Recording)

Формирование батчей SQL-запросов по окончании операции.

| Латинский префикс (Test ID) | Фича / Узел графа | Пояснение для тестов |
| --- | --- | --- |
| `export_cycle_rec` | Запись Operating Cycle | Создание записи в `rec_operating_cycle` с таймстемпами старта/стопа и Alarm Class. |
| `export_cycle_metric` | Запись Operating Metric | Сброс привязанных к ID цикла метрик `average_load` и `max_load` в таблицу `rec_operating_metric`. |

### 5. Живые события и телеметрия (Live Data & Events)

Транзитный экспорт потоковых данных (Live) в шину с динамической компрессией.

| Латинский префикс (Test ID) | Фича / Узел графа | Пояснение для тестов |
| --- | --- | --- |
| `live_dynamic_deadband` | Динамический порог | Расчет плавающего `craneLoadThreshold` через `PiecewiseLineApprox` (от 30% на пустом крюке до 0.1% на максималках). |
| `live_load_filter` | Компрессия нагрузки | Отсечение шума датчиков веса (`FnThreshold` с фактором 0.05). |
| `live_export_load` | Экспорт телеметрии веса | Отправка отфильтрованных значений `CraneLoadEvent` и `WinchXLoadEvent` в очередь API. |
| `live_export_safety` | Экспорт событий безопасности | Моментальная отправка событий `CraneMOPS` и `CraneAOPS` строго при изменении состояния (`FnIsChangedValue`). |
