# Functions of Task service

## Правила написания функций

Любая **«нечистая»** (impure) функция, которая черпает данные извне графа (системное время, генератор случайных чисел, чтение из внешней БД), **всегда возвращает `Flow::New`**, если ее значение физически изменилось с прошлого вызова.
Это заставит все зависимые от нее узлы с состоянием (счетчики, интеграторы) честно отработать свои вычисления.

### Разделение входов функций (Как заражать `Flow`)

- **Триггеры/Данные (Input) - Участвуют в `Flow`**

    Это пульс системы. Изменение этих данных является причиной для расчетов. Они **обязаны заражать `Flow`**.
    - input
    - enable
    - reset
    - trigger
    - gate
    - pass

- **Параметры (Config) - Не участвуют в `Flow`:**

    Это вспомогательные данные. Тот факт, что уставка или начальное значение обновились (или были прочитаны в первый раз), сам по себе не должен провоцировать ложное срабатывание счетчика. Счетчик тикает только от фронта на входе.
    - initial
    - threshold
    - factor
    - delay
    - coefficients
    - piecewise

### Поведение функций (Taint Tracking)

1. **Воды (FnInput):**
* Возвращают `New`, только если `updated_at_cycle == current_cycle`. Иначе `Old`.
* *Отвечают за точку отсчета.*

2. **Генераторы (FnTimer, FnRandom):**
* Возвращают `New`, если сгенерированное значение отличается от прошлого (или просто всегда возвращают `New`, что проще и надежнее).
* *Выступают спонтанными источниками изменений.*

3. **Чистая математика (FnAdd, FnMath):**
* Возвращают `New`, если **хотя бы один** аргумент имеет статус `New`. Иначе `Old`.
* *Математика сама по себе не создает событий, она только проводит их.*

4. **Узлы с состоянием (FnCount, FnIntegrator, FnRisingEdge):**
* Анализируют аргументы. Если пришел `New` (от входа или таймера) — мутируют свой внутренний стейт (прибавляют счетчик, вычисляют интеграл). Возвращают `New`.
* Если все аргументы `Old` — ничего не считают, просто отдают свой старый кэш со статусом `Old`.

5. **Обертка (FnEvalOnce):**
* Честно кэширует статус `Flow` и значение `Point` для текущего вычислительного цикла. Спасает от повторных вычислений чистой математики, если ее дергают из разных веток графа в один цикл несколько раз.

- **Retain**

Stores Point value on the disk if [input] is specified  
Returns stored value as a point, reads stored value only once

>**Example**
>
>```yaml
>fn Retain:
>    key: Ied13.Load
>    enable: const bool true
>    input: point real /App/Ied13/Load
>```
